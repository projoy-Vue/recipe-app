# 🍲 Recipe App

A user-friendly recipe finder built with Vue.js, HTML, CSS, and JavaScript.

## 🚀 Features
- Search recipes by name or ingredients.
- Filter recipes by categories (e.g., Vegetarian, Vegan, Desserts).
- Dynamic recipe details with ingredients and steps.
- Mobile-friendly responsive design.

## 🛠️ Tech Stack
- **Frontend:** Vue.js, HTML, CSS
- **Build Tool:** Vite
